AI Workbench Workshop: Build Your Own Harness

Build a personal, reproducible AI engineering environment from a 100% free and open source stack. It works with Python, JavaScript/TypeScript, Java, C/C++, Go, Rust, or any language your projects use.

In hands-on labs you will:
• Install and configure the OpenCode harness and its plugins
• Connect MCP (Model Context Protocol) servers to files, databases, APIs and your own scripts, with access you approve
• Write reusable skills for code generation, review, testing, documentation and research
• Use graph tools to explore codebases, dependencies and architecture
• Run open models locally or self-hosted, with Git and documentation workflows
• Build at least one custom MCP or automation of your own

Research in the AI era: use the same workbench to search the literature, summarise papers with citations, reproduce experiments and draft in LaTeX or Markdown, while you verify every claim.

For undergraduates, engineers and faculty: academic projects, hackathons, internships, research and open-source contributions.
